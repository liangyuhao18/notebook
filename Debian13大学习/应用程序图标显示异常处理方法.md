1. 前往/usr/share/applications下面检查是否有对应程序的.desktop文件。若没有，创建一个。
2. 右键使用文本编辑器打开对应的.desktop文件，会有如下内容（以QQ为例）：
```
[Desktop Entry]
Name=QQ              # 应用程序名字
Exec=/opt/QQ/qq %U   # 启动命令
Terminal=false       # 是否在终端运行
Type=Application     # 文件类型，常用值
                     # 'Applicantion':应用程序 'Link':URL链接 'Directory':文件夹
Icon=/usr/share/icons/hicolor/512x512/apps/qq.png # 图标名称或绝对路径。
                                    # 若图标在系统图标主题中，直接填名称（无需扩展名）
StartupWMClass=QQ    # 窗口管理器类名，用于任务栏分组（需与应用窗口的 `WM_CLASS` 一致
Categories=Network;  # 应用程序分类（决定菜单位置）
Comment=QQ           # 简短描述（鼠标悬停时显示）
```
### 若应用菜单和桌面的图标显示异常
1. 首先检查Icon对应的路径是否存在或应用名称是否正确。如果正确，检查/usr/share/icons/hicolor/下的每一个文件夹，会有两种情况：
	- 检查文件夹发现不存在对应应用程序的图标。则创建一个，把路径填入Icon项中。
	- 存在图标，但是分辨率太高，图标索引系统索引失败。则可以使用**ImageMagick**工具resize图标，流程如下：
	1. 安装ImageMagick:
	```
	# Debian/Ubuntu
	sudo apt install imagemagick 
	# 验证安装
	convert --version 
	# 输出 ImageMagick 版本信息，如 "ImageMagick 6.9.11-60 Q16 x86_64"
	```
	2. 调整图标
	```
	# 基础语法
	convert [输入文件] [resize 参数] [输出文件]
	
	# 按比例缩放（推荐）
	convert input.jpg -resize 50% output.jpg # 将input.jpg缩小至50%
	
	# 固定宽/高（保持比例）
	固定宽度：`-resize W`（仅指定宽度，高度按比例计算）
	固定高度：`-resize xH`（仅指定高度，宽度按比例计算）
	convert input.jpg -resize 800 output.jpg  # 固定宽度为 800px（高度自动）
	convert input.jpg -resize x600 output.jpg # 固定高度为 600px（宽度自动）
	
	# 强制固定尺寸 
	convert input.jpg -resize 800x600! output.jpg # 强制将图片调整为800x600
	```
		将调整后的图标放入其中的一个文件夹中，将路径填入.desktop的Icon项中

2. 完成上述步骤之后刷新图标缓存
```
sudo update-desktop-database
```
### 若任务栏(或者叫dock栏)图标显示异常
这个问题一般是**StartupWMClass**[^1]字段的名字和应用程序名字不对应造成的。

1. 打开图标显示异常的应用程序，打开终端，输入：
```
xprop WM_CLASS
```
	然后鼠标会变成一个十字形，点击该应用，终端会输出以下信息(以QQ为例)：
```
WM_CLASS(STRING) = "qq", "QQ"
```

2. 需要的是**第二个字符串**（通常是更具体的应用程序名称），记住这个字符串（不带引号）。使用文本编辑器打开QQ的.desktop文件。
```
sudo nano /usr/share/applications/qq.desktop
```
	将StartupWMClass字段的修改为刚才找到的字符串，如：
```
StartupWMClass=QQ
```
	修改完毕后保存，刷新：
```
sudo update-desktop-database
```

[^1]: 现代Linux桌面环境使用`WMClass`属性将窗口与所属应用程序关联起来。许多基于Java的应用程序存在一个问题，即应用程序创建的窗口与启动应用程序的快捷方式不关联（因此，坞站包含多个相同图标的副本）。 因此，名为**StartupWMClass**的字段是一个字符串，用于定义在Unity Launcher中启动时应用程序所属的类别。请注意，这是一个X11的概念。在使用Wayland的系统上，`xprop`工具将不再起作用。
